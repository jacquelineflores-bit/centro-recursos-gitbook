# v2.7 (Julio 2019)

Funcionalidades y mejoras incluidas:

- Caducidad de Comunicaciones:

* Posibilidad de habilitar la caducidad de las Comunicaciones.
* Configuración del plazo (en días) para que una comunicación se considere caducada o vencida.
* Vista específica para consultar, descargar o eliminar las Comunicaciones Caducadas.

- Mayor Detalle en Logs de Conexiones y Acciones:

* Nuevas columnas para poder consultar y flitrar por dichos campos.
* Vista de detalle donde se muestran todos los campos por completo.
