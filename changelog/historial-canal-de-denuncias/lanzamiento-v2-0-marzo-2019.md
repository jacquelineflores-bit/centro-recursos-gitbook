# Lanzamiento v2.0 (Marzo 2019)

Se libera la nueva versión de GlobalSUITE@ Whistleblower Channel.

El Canal de Denuncias es una herramienta que permite comunicar, de manera confidencial y con un sencillo formulario, las actividades y conductas potencialmente irregulares que puedan suponer un incumplimiento del Código de Conducta y/o la posible comisión de un delito penal.

Principales características:

- Multidisposivo (Responsive)

- Multidioma

- Asesoría sobre tratamientos y procedimientos

- Mejores prácticas de Seguridad y continuidad

- Adecuado al RGPD

- Notificaciones

- Trazabilidad en todo el proceso

- Nº de comunicaciones ilimitado

- Personalización corporativa

- Encriptación en todas las Comunicaciones
