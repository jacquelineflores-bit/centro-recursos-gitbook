# v3.17 (Octubre 2023)

## Funcionalidades y mejoras incluidas:

* **Nuevos formatos de archivo permitidos**

A partir de esta versión, será posible incluir adjuntos con formato **.wav** y **.wma** tanto en el [formulario de una comunicación](https://help.globalsuite.es/display/CD/Alta+de+Comunicados), como en el seguimiento y gestión interna del Canal.

* Este formato de archivo .wma es el utilizado en la funcionalidad de grabación de audios con distorsión de voz que se incorporó en la [versión 3.10](https://help.globalsuite.es/pages/viewpage.action?pageId=117637142) de GlobalSuite® Whistleblower Channel.

De esta forma, es posible procesar el archivo (recortándolo) para volver a adjuntarlo en la comunicación, o poder realizar grabaciones de forma externa y cargarlas como adjunto a la propia denuncia.

* También, el formato .wav es el utilizado por el servicio de centralita telefónica, que es un canal alternativo al formulario web para registrar comunicaciones o denuncias de forma confidencial.

Estos archivos de voz recibidos mediante el canal telefónico, se podrán cargar en la solución para su gestión y tratamiento de forma centralizada.
