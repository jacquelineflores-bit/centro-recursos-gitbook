# v2.51 (Septiembre 2021)

Funcionalidades y mejoras incluidas:

- **Entorno Secundario**:

* Ahora es posible visualizar el Asunto o Resumen definido para una comunicación, cuando se envía al entorno secundario o repositorio de denuncias.

 - **Seguimiento** de asignación de Gestores: Se incluye un seguimiento automático en el timeline de una denuncia cuando se asocia o desasocia un gestor a la misma.

- Mejoras internas y resolución de errores.
