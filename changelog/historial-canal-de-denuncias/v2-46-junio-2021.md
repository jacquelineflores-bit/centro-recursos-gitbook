# v2.46 (Junio 2021)

Funcionalidades y mejoras incluidas:

- Nuevos Idiomas disponibles:

* Francés
* Alemán
* Brasileño (pt-BR)

- Mejoras en **Categorización** de denuncias:

* Se ha ampliado el tamaño de texto para poder introducir nombres de categorías o tipos de denuncias más extensas.
* Además, se ha ajustado el comportamiento para que las categorías o tipos de comunicación se puedan gestionar únicamente mientras la comunicación no está cerrada.

- Mejoras internas y resolución de errores.
