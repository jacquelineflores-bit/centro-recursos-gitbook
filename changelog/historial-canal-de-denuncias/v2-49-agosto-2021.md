# v2.49 (Agosto 2021)

Funcionalidades y mejoras incluidas:

- Nuevo funcionalidad para incorporar un **Asunto** o resumen a cada caso:

* Posibilidad de habilitar un campo interno asunto (o identificador), para indicar un resumen o código único que facilite la gestión de cada comunicación recibida.
* Este campo será visible en el listado principal de Comunicaciones, y se podrán realizar búsquedas sobre el mismo, para simplificar su identificación o localización.
* Asimismo, en caso de estar habilitado también se incluirá en los informes que se pueden obtener de la herramienta, tanto en formato CSV como el informe PDF detallado de un caso.

 - Nueva versión de **Condiciones de Uso** de GlobalSUITE® Whistleblower Channel:

* Se han actualizado las condiciones de uso para nuestros clientes y usuarios. Estas condiciones deberán ser revisadas y aceptadas en el primer acceso, tras la actualización.
* Los comunicadores o denunciantes (anónimos o no) seguirán debiendo aceptar las [condiciones de uso que configure cada cliente en su canal](https://help.globalsuite.es/display/CD/Configuraciones+Consulting), antes de registrar una nueva comunicación.
