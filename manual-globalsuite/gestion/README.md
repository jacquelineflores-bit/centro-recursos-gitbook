# Gestión

{% hint style="info" %}
La opción Gestión en GlobalSuite® reúne herramientas esenciales para la administración de varios aspectos organizativos. Dentro de esta sección, se encuentra la Gestión de empleados, que permite el manejo de datos y perfiles de los empleados. Además, incluye la Gestión de encuestas, con opciones para crear y administrar encuestas de distintos tipos, como encuestas de Elemento Riesgo y controles, BIAS, y RRHH, entre otras. También se ofrece la Gestión de tickets, donde se pueden gestionar diversos tipos de tickets, incluyendo no conformidades, incidencias y problemas, entre otros. Esta sección facilita un control integral y personalizado de las gestiones internas clave en la organización.
{% endhint %}
