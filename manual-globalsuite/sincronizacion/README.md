# Sincronización

En varias secciones de la herramienta GlobalSuite existe la posibilidad de sincronizarse con otras herramientas, previamente configuradas en [Home](http://manual.globalsuite.es/index.php/Home), en el menú 2.6 Conexiones. A continuación se detallaran distintas formas de conexión.

* [OSSIM](ossim.md)
* [OCS Inventory](ocs-inventory.md)
* [SAML](saml.md)
* [Active Directory / LDAP](active-directory-ldap.md)
* [Sincronización E-Mail](sincronizacion-e-mail.md)
