# ScoreCard

{% hint style="info" %}
La opción ScoreCard permite a los usuarios generar un cuadro de mando para medir la eficiencia del Sistema de Gestión implementado en la organización. Con las herramientas proporcionadas, se facilita la evaluación, control y seguimiento de la estrategia organizativa.
GlobalSuite® ofrece, a través de esta opción, una visión gráfica y global de los resultados de las acciones de seguimiento, permitiendo comprobar rápidamente si el desempeño y eficiencia de la organización cumplen con los objetivos establecidos, tanto en el sistema de gestión como en la estrategia general, mediante un sistema de indicadores claros y accesibles.
{% endhint %}
