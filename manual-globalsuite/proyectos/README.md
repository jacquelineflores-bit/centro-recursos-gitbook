# Proyectos

{% hint style="info" %}
La opción \*\*Proyectos\*\* en GlobalSuite® ofrece las herramientas necesarias para crear y gestionar un proyecto que coordine las tareas del Sistema de Gestión.
Este apartado está disponible en el menú izquierdo y contiene funcionalidades clave para controlar y organizar cada etapa del proyecto. Dentro de Proyecto, se incluyen opciones como la Gestión de proyectos, que permite el control y la planificación detallada, con la posibilidad de crear historiales para un seguimiento completo; el Equipo de trabajo, donde se definen los empleados asignados al proyecto; y el Calendario, que traduce la gestión del proyecto a una vista visual para facilitar su seguimiento.
{% endhint %}
