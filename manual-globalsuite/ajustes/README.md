# Ajustes

{% hint style="info" %}
La opción \*\*Ajustes\*\*, ubicada en la parte inferior del menú principal, permite a los usuarios consultar y gestionar los datos de su empresa dentro de la plataforma, ayudando a mantener la información actualizada y correcta. Al seleccionar \*\*Ajustes\*\*, se despliegan las opciones de configuración disponibles según el nivel de acceso del usuario.
Los usuarios con perfil de administrador tienen acceso a opciones adicionales para configurar aspectos como la gestión de usuarios, la personalización de la plataforma y las configuraciones de seguridad.
{% endhint %}
