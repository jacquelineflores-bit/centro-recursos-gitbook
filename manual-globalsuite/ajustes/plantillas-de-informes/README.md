# Plantillas de Informes

{% hint style="info" %}
Esta funcionalidad permite generar informes personalizables tanto en formato \*\*Word\*\* como en \*\*Excel\*\*, mediante plantillas que pueden adaptarse a las necesidades de cada organización.
Estos informes se alimentan automáticamente con los datos del sistema mediante un conjunto de \*\*variables\*\*, facilitando la generación de documentación formal, evidencias o reportes de seguimiento.
{% endhint %}

Actualmente, esta funcionalidad está disponible en tickets, auditoría, análisis de riesgo, entre otros.

## ¿Qué tipo de plantillas puedo utilizar?

GlobalSuite® soporta los siguientes tipos de plantillas:

* **Plantillas en Word (.docx):** ideales para informes narrativos, documentos extensos o reportes que requieren formato formal con tablas, encabezados y textos estructurados.
* **Plantillas en Excel (.xlsx):** Permiten representar información estructurada como listados, tablas, etc.

> 📌 En cada tipo de plantilla se utilizan variables específicas para insertar información del sistema en los informes.

## Descargar y Subir plantilla

Para ambos formatos, es posible descargar plantillas predefinidas, proporcionada por GlobalSuite®, personalizarla de acuerdo a tus necesidades y subirla al sistema para poder configurarla.  
En cada sección encontrarás el detalle específico para cada tipo de plantilla y las plantillas predefinidas disponibles.

## Listado de Plantillas

Al acceder a la opción, se muestran todas las plantillas existentes junto con su información: nombre, tipo, extensión, descripción, fecha y hora de creación, y si están activas o no.

Las acciones disponibles en esta tabla son:

* **Eliminar**: seleccionando la plantilla a eliminar mediante el check.
* **Descargar**: permite descargar la plantilla seleccionada.

## Detalle de Plantilla

En esta sección, podrás realizar las siguientes acciones sobre la plantilla:

* Editar el nombre de la plantilla.
* Activar o desactivar la plantilla según sea necesario.
* Configurar la visibilidad: Según el tipo de plantilla, se mostrará el módulo desde el cual podrá ser descargada con los datos correspondientes.
