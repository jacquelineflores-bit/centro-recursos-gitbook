# Opciones específicas para licencias Consulting, Gold y Platinum

A continuación se detallan las funcionalidades adicionales que están disponibles para las empresas organizativas, con licencias Consulting, Gold o Platinum.

Todas las opciones se encuentran en la pestaña "Mi Empresa" cuando se accede con un usuario de tipo Consulting, Gold o Platinum.

También se mostrará la pestaña "Clientes", que permite administrar y gestionar los entornos que dependen del suyo.

* [Alertas Organizativas](alertas-organizativas.md)
* [Gestión Informes](gestion-informes.md)
* [Calendario Organizativo](calendario-organizativo.md)
* [Usuarios Organizativos](usuarios-organizativos.md)
