# Metodologías

El apartado **Metodologías** permite gestionar la configuración de las diferentes metodologías utilizadas en GlobalSUITE®. Estas incluyen la evaluación de elementos, riesgos, controles y auditorías. Desde este espacio, es posible definir los criterios, escalas y parámetros necesarios para ajustar cada metodología a las necesidades específicas de la organización.

A continuación, se presentan enlaces directos a cada una de las opciones de esta sección para acceder a sus detalles y configuraciones.

* [Metodología Elementos](metodologia-elementos.md)
* [Metodología Riesgos](metodologia-riesgos.md)
* [Metodologías Controles](metodologias-controles.md)
* [Metodologías Auditorías](metodologias-auditorias.md)
