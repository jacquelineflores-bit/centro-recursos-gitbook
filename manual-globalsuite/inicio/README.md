# Inicio

{% hint style="info" %}
La sección Inicio en GlobalSuite® proporciona las opciones y apartados necesarios para la configuración y definición inicial del sistema. Esta sección incluye herramientas para ajustar y definir el sistema según las necesidades de la empresa, y las opciones disponibles pueden variar dependiendo de los módulos y licencias contratadas, así como de los permisos asignados al usuario que ha iniciado sesión
