# Análisis

{% hint style="info" %}
La sección Análisis en GlobalSuite® agrupa las herramientas necesarias para realizar evaluaciones y análisis clave en la identificación, evaluación y gestión de riesgos. Este apartado permite a las organizaciones llevar a cabo un análisis integral de su exposición a riesgos y definir estrategias de mitigación que contribuyan a una gestión eficiente de los mismos. Entre los tipos de análisis disponibles se encuentran el Análisis BIA, el Análisis y Evaluación de Riesgos, así como opciones para gestionar los riesgos y los controles necesarios para su mitigación.
{% endhint %}
