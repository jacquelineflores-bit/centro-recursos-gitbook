# Planes de Recuperación

Esta opción de Plan de Recuperación permite establecer los criterios de activación del plan de recuperación, responsables de gestionar la recuperación, tareas a seguir para volver a una situación estable, así como cualquier otra información útil que permita proceder de forma correcta para establecer la recuperación de la incidencia.

Esta opción consta de dos apartados principales:

* [Plan de Recuperación](plan-de-recuperacion.md)
* [Secuencia de Recuperación](secuencia-de-recuperacion.md)
