# Planes

{% hint style="info" %}
La opción Planes en GlobalSuite® permite gestionar diversos planes críticos para la organización, abarcando áreas clave como la continuidad del negocio, capacidad operativa, recuperación, disponibilidad, estrategias, formación y capacitación, escenarios de desastre y crisis, y programas de pruebas. Esta sección centraliza la administración de estos planes, facilitando su implementación, seguimiento y actualización para asegurar una respuesta eficaz ante diferentes situaciones y riesgos
{% endhint %}
