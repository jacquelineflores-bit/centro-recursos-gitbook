# Infraestructura Cloud

De manera general, todos nuestros productos son puestos a disposición de nuestros clientes a través de un formato SaaS (Software-as-a-Service), permitiendo disfrutar de los servicios sin la complejidad de la gestión de dicha infraestructura y garantizando unas condiciones de confidencialidad, disponibilidad e integridad suficientes gracias a la arquitectura implementada y a los diferentes controles implementados.

Según nuestro modelo de licenciamiento, nuestra infraestructura compartirá distintos recursos con el resto de usuarios, es lo que conocemos como una arquitectura multi-tenant.
