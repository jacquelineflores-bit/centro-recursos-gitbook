# Marketplace - Integraciones GlobalSuite

## Bienvenido al Marketplace de Integraciones GlobalSuite

![Banner Home _960px _ Open Menu-20250616-121540.png](.gitbook/assets/1187709421-banner-home-960px-open-menu-20250616-121540.png)
{% hint style="info" %}
GlobalSuite Marketplace es una plataforma diseñada para extender y potenciar las capacidades de \*\*GlobalSuite GRC\*\*, permitiendo una integración sencilla, segura y eficiente con otras herramientas comerciales o corporativas utilizadas en tu organización.
Gracias a este ecosistema de conectores, podrás automatizar flujos de trabajo, sincronizar información clave y mejorar la interoperabilidad con sistemas externos agilizando la comunicación, evitando duplicidades y poniendo el GRC como pilar central de la gestión.
{% endhint %}

### ¿Qué puedes hacer con el Marketplace?

* **Explorar conectores disponibles** por categoría, ámbito o funcionalidad.
* **Instalar conectores de forma rápida** y segura desde una única solución centralizada.
* **Configurar sincronizaciones** con sistemas externos sin necesidad de desarrollos complejos.
* **Mantener tus conectores actualizados** con nuevas capacidades y casos de uso ampliados que vayamos incorporando en próximas versiones.
* **Revisar** las sincronizaciones activas**, monitorizar** su estado, pausar o actualizarlas
* **Acceder a documentación técnica y funcional** de cada conector desde la misma plataforma.

### Seguridad y Disponibilidad

Cada conector del Marketplace utiliza mecanismos robustos y seguros para realizar la comunicación de la información mediante mecanismos seguros de autenticación, protocolos cifrados y validación de integridad de los datos.

Este Marketplace de GlobalSuite se apoya en **Apache Kafka**, una tecnología que permite gestionar el flujo de información con múltiples características:

* alta escalabilidad
* baja latencia
* tolerancia a fallos
* durabilidad de los datos
* capacidad de procesar grandes volúmenes de datos en tiempo real

Si quieres ver más información, consulta este artículo [Arquitectura Kafka para el Marketplace](https://globalsuitesolutions.atlassian.net/wiki/spaces/MIG).

### ¿A quién va dirigido el Marketplace?

Esta solución está pensada para:

* **Administradores técnicos**, que desean facilitar la integración de GlobalSuite con sistemas propios o de terceros.
* **Usuarios de negocio**, que buscan automatizar procesos y eliminar tareas manuales mediante conectores certificados.
* **Partners**, que quieran publicar sus propios conectores y extender el ecosistema GlobalSuite.

### Requisitos previos

Antes de comenzar, asegúrate de:

* Tener activa la licencia de GlobalSuite Marketplace en tu instancia de GlobalSuite GRC
* Contar con un usuario autorizado en GlobalSuite.
* Disponer de las credenciales y permisos necesarios para conectarte a los sistemas externos.
* Revisar los requisitos previos de cada conector antes de su instalación.
