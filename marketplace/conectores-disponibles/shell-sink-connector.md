## Detalles

El conector Shell Sink Connector permite enviar desde GlobalSuite hacia Shell información relacionada con registros, eventos y datos operativos.

Es útil cuando Shell debe actuar como sistema de destino, explotación, archivo o monitorización para casos de intercambio controlado de información, automatización de tareas repetitivas y seguimiento de procesos entre sistemas.

## Características

* Envío controlado de registros, eventos y datos operativos desde GlobalSuite hacia Shell o hacia el repositorio destino definido.
* Configuración del alcance, periodicidad, formato y mapeo para adaptarlo al proceso de negocio.
* Soporte a pruebas controladas antes de ampliar el uso a entornos productivos.
* Trazabilidad de ejecuciones para revisar resultados y detectar incidencias de integración.
* Diseño reutilizable para reducir desarrollos a medida entre aplicaciones.

## Beneficios clave

* Reduce tareas manuales y errores de transcripción entre sistemas corporativos.
* Permite mantener procesos actualizados con información procedente de herramientas especializadas.
* Facilita pruebas controladas antes de ampliar el alcance a más áreas o datos.
* Mejora la trazabilidad de resultados y responsabilidades en flujos transversales.
* Acelera la puesta en marcha de casos de uso sin desarrollar integraciones desde cero.

## Instalación

|  |
| --- |
| **Nota de configuración:** Antes de activar la integración, valida credenciales, permisos, alcance funcional y una prueba de datos con el área responsable. |

1. Accede al Marketplace de GlobalSuite® y selecciona Shell Sink Connector.
2. Configura el destino en Shell: URL o endpoint, credenciales, permisos y entorno.
3. Define qué información se enviará: registros, eventos y datos operativos, filtros, formato y periodicidad.
4. Mapea los campos de GlobalSuite con la estructura esperada por el sistema destino.
5. Ejecuta una prueba, revisa la recepción en destino y activa la integración.

## Uso recomendado en GlobalSuite

Utiliza este conector cuando necesites enviar información de GlobalSuite a Shell, por ejemplo para intercambio controlado de información, automatización de tareas repetitivas y seguimiento de procesos entre sistemas. Antes de publicarlo, valida con el equipo propietario del sistema destino el formato esperado, permisos, frecuencia y criterios de calidad.
