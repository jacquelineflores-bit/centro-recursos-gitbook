## Detalles

El conector Security ScoreCard Source Connector permite incorporar a GlobalSuite información procedente de Security ScoreCard relacionada con indicadores, hallazgos y evidencias de seguridad.

Está orientado a mantener actualizados procesos de gestión, evidencias e indicadores sin depender de cargas manuales, especialmente en escenarios de evaluación de terceros, priorización de vulnerabilidades, seguimiento de planes de tratamiento y reporting de postura de seguridad.

## Características

* Incorporación configurable de indicadores, hallazgos y evidencias de seguridad desde Security ScoreCard hacia los procesos de GlobalSuite.
* Asociación de hallazgos con proveedores, activos, riesgos o controles para facilitar su seguimiento.
* Actualización de indicadores de exposición, criticidad o cumplimiento con criterios definidos por la organización.
* Soporte a filtros por alcance, criticidad, origen o responsable para concentrarse en lo realmente accionable.
* Trazabilidad de cambios para evidenciar evolución de la postura de seguridad y justificar decisiones.

## Beneficios clave

* Permite priorizar proveedores, activos o vulnerabilidades con información objetiva y actualizada.
* Reduce el tiempo dedicado a recopilar evidencias técnicas para evaluaciones, auditorías o comités de riesgo.
* Facilita detectar cambios relevantes de postura de seguridad antes de que impacten en el negocio.
* Ayuda a justificar planes de tratamiento y responsables con datos trazables.
* Mejora la coordinación entre seguridad, riesgos, compras y áreas propietarias del servicio.

## Instalación

|  |
| --- |
| **Nota de configuración:** Antes de activar la integración, valida credenciales, permisos, alcance funcional y una prueba de datos con el área responsable. |

1. Accede al Marketplace de GlobalSuite® y selecciona Security ScoreCard Source Connector.
2. Configura la conexión con Security ScoreCard: URL o endpoint, credenciales, permisos y entorno.
3. Define el alcance funcional de la sincronización: indicadores, hallazgos y evidencias de seguridad, filtros y frecuencia.
4. Mapea los campos recibidos con las entidades, evidencias o procesos correspondientes de GlobalSuite.
5. Ejecuta una prueba, revisa los registros sincronizados y activa la integración.

## Uso recomendado en GlobalSuite

Utiliza este conector cuando necesites incorporar información de Security ScoreCard en procesos de GlobalSuite, por ejemplo para evaluación de terceros, priorización de vulnerabilidades, seguimiento de planes de tratamiento y reporting de postura de seguridad. Antes de publicarlo, acuerda con el área propietaria qué datos son necesarios, con qué frecuencia deben actualizarse y quién revisará los resultados.
