## Detalles

El conector OPC Router 4 Sink Connector permite enviar desde GlobalSuite hacia OPC Router 4 información relacionada con telemetría industrial, eventos IoT y señales de dispositivos.

Es útil cuando OPC Router 4 debe actuar como sistema de destino, explotación, archivo o monitorización para casos de seguimiento de activos industriales, alertas de operación, trazabilidad de dispositivos y continuidad operativa.

## Características

* Envío controlado de telemetría industrial, eventos IoT y señales de dispositivos desde GlobalSuite hacia OPC Router 4 o hacia el repositorio destino definido.
* Captura o entrega de telemetría, señales industriales o eventos de dispositivos para casos operativos.
* Mapeo de dispositivos, activos, plantas o líneas de producción con entidades gestionadas en GlobalSuite.
* Soporte a alertas sobre disponibilidad, seguridad, continuidad o comportamiento anómalo.
* Configuración por origen, dispositivo o variable para limitar el alcance a información relevante.

## Beneficios clave

* Permite llevar datos de planta, dispositivos o activos conectados a procesos de riesgo, continuidad o mantenimiento.
* Acelera la detección de anomalías operativas que puedan afectar a servicios críticos.
* Facilita relacionar telemetría con activos, controles, ubicaciones o responsables.
* Reduce la distancia entre equipos OT, IT, seguridad y cumplimiento.
* Apoya casos de continuidad operativa, seguridad industrial y seguimiento de activos en tiempo real.

## Instalación

|  |
| --- |
| **Nota de configuración:** Antes de activar la integración, valida credenciales, permisos, alcance funcional y una prueba de datos con el área responsable. |

1. Accede al Marketplace de GlobalSuite® y selecciona OPC Router 4 Sink Connector.
2. Configura el destino en OPC Router 4: URL o endpoint, credenciales, permisos y entorno.
3. Define qué información se enviará: telemetría industrial, eventos IoT y señales de dispositivos, filtros, formato y periodicidad.
4. Mapea los campos de GlobalSuite con la estructura esperada por el sistema destino.
5. Ejecuta una prueba, revisa la recepción en destino y activa la integración.

## Uso recomendado en GlobalSuite

Utiliza este conector cuando necesites enviar información de GlobalSuite a OPC Router 4, por ejemplo para seguimiento de activos industriales, alertas de operación, trazabilidad de dispositivos y continuidad operativa. Antes de publicarlo, valida con el equipo propietario del sistema destino el formato esperado, permisos, frecuencia y criterios de calidad.
