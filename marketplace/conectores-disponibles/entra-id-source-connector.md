## Detalles

El conector Entra Id Source Connector permite incorporar a GlobalSuite información procedente de Entra Id relacionada con usuarios, grupos, roles y atributos de identidad.

Está orientado a mantener actualizados procesos de gestión, evidencias e indicadores sin depender de cargas manuales, especialmente en escenarios de alta y baja de usuarios, asignación de roles, control de accesos y revisión periódica de permisos.

## Características

* Incorporación configurable de usuarios, grupos, roles y atributos de identidad desde Entra Id hacia los procesos de GlobalSuite.
* Mapeo de usuarios, grupos y atributos corporativos con roles o perfiles funcionales de GlobalSuite.
* Soporte a procesos de alta, baja y modificación de accesos con menor intervención manual.
* Aplicación de filtros por unidades organizativas, colectivos o grupos para limitar el alcance.
* Trazabilidad de sincronizaciones para revisiones de acceso, auditorías y segregación de funciones.

## Beneficios clave

* Mantiene usuarios y roles alineados con el directorio corporativo, reduciendo errores de alta y baja.
* Facilita revisiones periódicas de acceso y evidencias para auditorías internas o externas.
* Reduce trabajo manual en mantenimiento de perfiles, empleados y permisos.
* Apoya la segregación de funciones y el gobierno de identidades en procesos GRC.
* Mejora la trazabilidad de quién tiene acceso, desde cuándo y bajo qué grupo o atributo.

## Instalación

|  |
| --- |
| **Nota de configuración:** Antes de activar la integración, valida credenciales, permisos, alcance funcional y una prueba de datos con el área responsable. |

1. Accede al Marketplace de GlobalSuite® y selecciona Entra Id Source Connector.
2. Configura la conexión con Entra Id: URL o endpoint, credenciales, permisos y entorno.
3. Define el alcance funcional de la sincronización: usuarios, grupos, roles y atributos de identidad, filtros y frecuencia.
4. Mapea los campos recibidos con las entidades, evidencias o procesos correspondientes de GlobalSuite.
5. Ejecuta una prueba, revisa los registros sincronizados y activa la integración.

## Uso recomendado en GlobalSuite

Utiliza este conector cuando necesites incorporar información de Entra Id en procesos de GlobalSuite, por ejemplo para alta y baja de usuarios, asignación de roles, control de accesos y revisión periódica de permisos. Antes de publicarlo, acuerda con el área propietaria qué datos son necesarios, con qué frecuencia deben actualizarse y quién revisará los resultados.
