## Detalles

El conector B.O.S. Software tcVISION Source Connector permite preparar, adaptar o proteger información antes de utilizarla en otros procesos de integración de GlobalSuite.

Es especialmente útil para sincronización de catálogos, auditoría de cambios, reporting regulatorio y eliminación de cargas manuales, asegurando que la información llegue al siguiente sistema con una estructura más limpia y gobernable.

## Características

* Aplicación de reglas de preparación sobre registros, tablas, colecciones y cambios de datos antes de su uso por otros sistemas.
* Selección de tablas, colecciones, vistas o campos para sincronizar sólo información con valor funcional.
* Soporte a altas, modificaciones y bajas cuando el sistema origen o destino lo permite.
* Mapeo de claves, campos y entidades para mantener coherencia con catálogos e inventarios corporativos.
* Trazabilidad de cambios y resultados para auditoría, conciliación y control de calidad de datos.

## Beneficios clave

* Mantiene catálogos, inventarios y registros críticos sincronizados con menor intervención manual.
* Reduce errores por duplicidad o desalineación entre bases de datos y procesos de GlobalSuite.
* Facilita auditoría de cambios, conciliación de información y reporting regulatorio.
* Permite incorporar información operativa al flujo GRC sin esperar exportaciones puntuales.
* Mejora la calidad del dato al trabajar con orígenes estructurados y reglas de mapeo definidas.

## Instalación

|  |
| --- |
| **Nota de configuración:** Antes de activar la integración, valida credenciales, permisos, alcance funcional y una prueba de datos con el área responsable. |

1. Accede al Marketplace de GlobalSuite® y selecciona B.O.S. Software tcVISION Source Connector.
2. Define el flujo en el que se aplicará la transformación y el orden respecto al resto de reglas.
3. Configura campos, expresiones, filtros o reglas de conversión necesarias para el caso de uso.
4. Valida el resultado con registros de prueba representativos.
5. Guarda la configuración y activa el flujo cuando el resultado sea correcto.
