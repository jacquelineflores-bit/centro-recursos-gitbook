## Detalles

El conector Advantco Kafka Adapter for SAP PO and Integration Suite Sink Connector permite enviar desde GlobalSuite hacia Advantco Kafka Adapter for SAP PO and Integration Suite información relacionada con datos de procesos SAP, maestros y objetos de negocio.

Es útil cuando Advantco Kafka Adapter for SAP PO and Integration Suite debe actuar como sistema de destino, explotación, archivo o monitorización para casos de sincronización de datos maestros, eventos de procesos, conciliación operativa y trazabilidad de controles sobre procesos SAP.

## Características

* Envío controlado de datos de procesos SAP, maestros y objetos de negocio desde GlobalSuite hacia el sistema destino definido.
* Integración de objetos de negocio, datos maestros o eventos de procesos SAP con procesos GRC.
* Mapeo de campos funcionales para alinear sociedad, centro, proveedor, activo, control o documento.
* Soporte a conciliaciones, seguimiento de aprobaciones y evidencias sobre procesos críticos.
* Configuración por entidad, objeto o servicio para adaptar el alcance al proceso de negocio.

## Beneficios clave

* Alinea procesos GRC con datos maestros y eventos de negocio ya existentes en SAP.
* Reduce duplicidades entre equipos funcionales, riesgos, cumplimiento y áreas operativas.
* Facilita controles sobre procesos críticos como compras, proveedores, activos, finanzas o producción.
* Mejora la trazabilidad entre transacciones, aprobaciones, evidencias y responsables.
* Permite acelerar conciliaciones y análisis sin depender de exportaciones manuales recurrentes.

## Instalación

|  |
| --- |
| **Nota de configuración:** Antes de activar la integración, valida credenciales, permisos, alcance funcional y una prueba de datos con el área responsable. |

1. Accede al Marketplace de GlobalSuite® y selecciona Advantco Kafka Adapter for SAP PO and Integration Suite Sink Connector.
2. Configura el destino en Advantco Kafka Adapter for SAP PO and Integration Suite: URL o endpoint, credenciales, permisos y entorno.
3. Define qué información se enviará: datos de procesos SAP, maestros y objetos de negocio, filtros, formato y periodicidad.
4. Mapea los campos de GlobalSuite con la estructura esperada por el sistema destino.
5. Ejecuta una prueba, revisa la recepción en destino y activa la integración.
