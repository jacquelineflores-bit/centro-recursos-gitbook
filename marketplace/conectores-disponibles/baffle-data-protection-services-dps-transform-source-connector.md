## Detalles

El conector Baffle Data Protection Services (DPS) Transform Source Connector permite preparar, adaptar o proteger información antes de utilizarla en otros procesos de integración de GlobalSuite.

Es especialmente útil para evaluación de terceros, priorización de vulnerabilidades, seguimiento de planes de tratamiento y reporting de postura de seguridad, asegurando que la información llegue al siguiente sistema con una estructura más limpia y gobernable.

## Características

* Aplicación de reglas de preparación sobre indicadores, hallazgos y evidencias de seguridad antes de su uso por otros sistemas.
* Asociación de hallazgos con proveedores, activos, riesgos o controles para facilitar su seguimiento.
* Actualización de indicadores de exposición, criticidad o cumplimiento con criterios definidos por la organización.
* Soporte a filtros por alcance, criticidad, origen o responsable para concentrarse en lo realmente accionable.
* Trazabilidad de cambios para evidenciar evolución de la postura de seguridad y justificar decisiones.

## Beneficios clave

* Permite priorizar proveedores, activos o vulnerabilidades con información objetiva y actualizada.
* Reduce el tiempo dedicado a recopilar evidencias técnicas para evaluaciones, auditorías o comités de riesgo.
* Facilita detectar cambios relevantes de postura de seguridad antes de que impacten en el negocio.
* Ayuda a justificar planes de tratamiento y responsables con datos trazables.
* Mejora la coordinación entre seguridad, riesgos, compras y áreas propietarias del servicio.

## Instalación

|  |
| --- |
| **Nota de configuración:** Antes de activar la integración, valida credenciales, permisos, alcance funcional y una prueba de datos con el área responsable. |

1. Accede al Marketplace de GlobalSuite® y selecciona Baffle Data Protection Services (DPS) Transform Source Connector.
2. Define el flujo en el que se aplicará la transformación y el orden respecto al resto de reglas.
3. Configura campos, expresiones, filtros o reglas de conversión necesarias para el caso de uso.
4. Valida el resultado con registros de prueba representativos.
5. Guarda la configuración y activa el flujo cuando el resultado sea correcto.
