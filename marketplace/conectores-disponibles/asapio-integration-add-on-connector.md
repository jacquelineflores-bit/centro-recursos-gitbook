## Detalles

El conector ASAPIO Integration Add-on Connector permite integrar GlobalSuite con ASAPIO Integration Add-on para intercambiar información relevante para procesos corporativos.

Es aplicable a escenarios de sincronización de datos maestros, eventos de procesos, conciliación operativa y trazabilidad de controles sobre procesos SAP, reduciendo cargas manuales y mejorando la trazabilidad.

## Características

* Gestión integrada de datos de procesos SAP, maestros y objetos de negocio entre GlobalSuite y ASAPIO Integration Add-on.
* Integración de objetos de negocio, datos maestros o eventos de procesos SAP con procesos GRC.
* Mapeo de campos funcionales para alinear sociedad, centro, proveedor, activo, control o documento.
* Soporte a conciliaciones, seguimiento de aprobaciones y evidencias sobre procesos críticos.
* Configuración por entidad, objeto o servicio para adaptar el alcance al proceso de negocio.

## Beneficios clave

* Alinea procesos GRC con datos maestros y eventos de negocio ya existentes en SAP.
* Reduce duplicidades entre equipos funcionales, riesgos, cumplimiento y áreas operativas.
* Facilita controles sobre procesos críticos como compras, proveedores, activos, finanzas o producción.
* Mejora la trazabilidad entre transacciones, aprobaciones, evidencias y responsables.
* Permite acelerar conciliaciones y análisis sin depender de exportaciones manuales recurrentes.

## Instalación

|  |
| --- |
| **Nota de configuración:** Antes de activar la integración, valida credenciales, permisos, alcance funcional y una prueba de datos con el área responsable. |

1. Accede al Marketplace de GlobalSuite® y selecciona ASAPIO Integration Add-on Connector.
2. Configura la conexión con ASAPIO Integration Add-on: URL o endpoint, credenciales, permisos y entorno.
3. Define el alcance funcional: datos de procesos SAP, maestros y objetos de negocio, filtros y frecuencia.
4. Configura el mapeo de campos y revisa la validación de la configuración.
5. Ejecuta una prueba, revisa resultados y activa la integración.
