## Detalles

El conector Google Cloud Storage Source Connector permite incorporar a GlobalSuite información procedente de Google Cloud Storage relacionada con ficheros, evidencias, documentos y objetos de almacenamiento.

Está orientado a mantener actualizados procesos de gestión, evidencias e indicadores sin depender de cargas manuales, especialmente en escenarios de retención de evidencias, intercambio de ficheros con terceros, archivo documental y explotación analítica posterior.

## Características

* Incorporación configurable de ficheros, evidencias, documentos y objetos de almacenamiento desde Google Cloud Storage hacia los procesos de GlobalSuite.
* Gestión de rutas, carpetas, contenedores o prefijos para ordenar la información por proceso o periodo.
* Compatibilidad con usos de archivo, intercambio de evidencias, respaldo documental o explotación posterior.
* Definición de formatos, filtros y criterios de selección para limitar el volumen importado o exportado.
* Trazabilidad sobre qué ficheros se han procesado, cuándo y con qué resultado.

## Beneficios clave

* Facilita conservar evidencias y documentación en repositorios corporativos ya gobernados.
* Reduce cargas manuales de ficheros y mejora la organización por proceso, tercero, control o periodo.
* Apoya políticas de retención, auditoría y respaldo documental con menor esfuerzo operativo.
* Permite compartir información con áreas internas o terceros usando ubicaciones controladas.
* Mejora la preparación de datos para reporting, data lake o análisis posteriores.

## Instalación

|  |
| --- |
| **Nota de configuración:** Antes de activar la integración, valida credenciales, permisos, alcance funcional y una prueba de datos con el área responsable. |

1. Accede al Marketplace de GlobalSuite® y selecciona Google Cloud Storage Source Connector.
2. Configura la conexión con Google Cloud Storage: URL o endpoint, credenciales, permisos y entorno.
3. Define el alcance funcional de la sincronización: ficheros, evidencias, documentos y objetos de almacenamiento, filtros y frecuencia.
4. Mapea los campos recibidos con las entidades, evidencias o procesos correspondientes de GlobalSuite.
5. Ejecuta una prueba, revisa los registros sincronizados y activa la integración.

## Uso recomendado en GlobalSuite

Utiliza este conector cuando necesites incorporar información de Google Cloud Storage en procesos de GlobalSuite, por ejemplo para retención de evidencias, intercambio de ficheros con terceros, archivo documental y explotación analítica posterior. Antes de publicarlo, acuerda con el área propietaria qué datos son necesarios, con qué frecuencia deben actualizarse y quién revisará los resultados.
