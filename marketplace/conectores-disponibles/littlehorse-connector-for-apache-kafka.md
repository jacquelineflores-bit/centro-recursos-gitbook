## Detalles

El conector LittleHorse Connector for Apache Kafka permite integrar GlobalSuite con LittleHorse for para intercambiar información relevante para procesos corporativos.

Es aplicable a escenarios de intercambio controlado de información, automatización de tareas repetitivas y seguimiento de procesos entre sistemas, reduciendo cargas manuales y mejorando la trazabilidad.

## Características

* Gestión integrada de registros, eventos y datos operativos entre GlobalSuite y LittleHorse for.
* Configuración del alcance, periodicidad, formato y mapeo para adaptarlo al proceso de negocio.
* Soporte a pruebas controladas antes de ampliar el uso a entornos productivos.
* Trazabilidad de ejecuciones para revisar resultados y detectar incidencias de integración.
* Diseño reutilizable para reducir desarrollos a medida entre aplicaciones.

## Beneficios clave

* Reduce tareas manuales y errores de transcripción entre sistemas corporativos.
* Permite mantener procesos actualizados con información procedente de herramientas especializadas.
* Facilita pruebas controladas antes de ampliar el alcance a más áreas o datos.
* Mejora la trazabilidad de resultados y responsabilidades en flujos transversales.
* Acelera la puesta en marcha de casos de uso sin desarrollar integraciones desde cero.

## Instalación

|  |
| --- |
| **Nota de configuración:** Antes de activar la integración, valida credenciales, permisos, alcance funcional y una prueba de datos con el área responsable. |

1. Accede al Marketplace de GlobalSuite® y selecciona LittleHorse Connector for Apache Kafka.
2. Configura la conexión con LittleHorse for: URL o endpoint, credenciales, permisos y entorno.
3. Define el alcance funcional: registros, eventos y datos operativos, filtros y frecuencia.
4. Configura el mapeo de campos y revisa la validación de la configuración.
5. Ejecuta una prueba, revisa resultados y activa la integración.
