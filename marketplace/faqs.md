# FAQs

En esta sección se muestran preguntas frecuentes sobre distintos aspectos del Marketplace de GlobalSuite.

**¿Qué es el Marketplace de Integraciones de GlobalSuite?**  
El Marketplace es una nueva aplicación dentro del ecosistema GlobalSuite que permite integrar fácilmente tu solución GRC con aplicaciones y sistemas externos mediante conectores predefinidos y configurables.

**¿Necesito conocimientos técnicos para configurar un conector?**  
No necesariamente. Utilizando la documentación de apoyo, es posible configurar un conector desde el Marketplace sin tener conocimientos técnicos.

Sin embargo, es necesario tener credenciales y permisos para realizar la conexión a los sistemas externos, los cuales pueden estar limitados por medidas de seguridad (autorización, controles perimetrales y de firewall) por lo que se recomienda contar con perfiles técnicos del lado del cliente.

**¿Puedo personalizar el comportamiento de una integración?**  
Sí. Se pueden configurar distintos aspectos:

* Frecuencia de lanzamiento
* Filtros por tipo de dato o alcance
* Fuente de origen
* Campos personalizados y mapeo con la configuración de GlobalSuite
* Comportamientos ante los registros obsoletos (eliminar / mantener)

**¿Qué limitaciones hay para el Marketplace?**  
El uso del marketplace va asociado al licenciamiento contratado. En función del tipo de licencia de GlobalSuite GRC se incluye un límite de conectores a activar.

En caso de que se haya superado el límite disponible, se puede contactar con el equipo comercial para ampliar a un licenciamiento superior.

**¿Qué necesito si quiero empezar a utilizar el Marketplace?**  
Si el Marketplace está incluido, puede solicitar su activación al [Centro de Soporte a Clientes](https://support.services.globalsuitesolutions.com/servicedesk/customer/portals).

También puede indicar qué usuarios de GlobalSuite van a tener acceso al Marketplace para que CSC los autorice.

**¿Qué ocurre si el conector que necesito no está disponible?**  
Si dentro del catálogo de conectores no hay un conector para una de tus aplicaciones corporativas o para un caso de uso específico, ponte en contacto con el responsable comercial para plantear una solución a medida.

En cualquier caso, el Marketplace de Integraciones de GlobalSuite está en constante evolución.
